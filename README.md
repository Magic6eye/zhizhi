# 芝芝 · GLM 御姐桌宠

> 「急什么，姐姐在呢。」——会站在你桌面上陪你干活的温柔御姐桌宠。
> 口头禅：**「芝士就是力量！」**（芝士 = 知识，智谱的"芝"；她心情好或被你夸的时候就会蹦出这句）
> 纯本地运行、零依赖、免安装，一个 exe 双击即用。

## 下载与运行

1. 下载本仓库的 `zhizhi.exe`（约 83MB）
2. 双击运行。**首次启动会自解压，黑窗/无反应请等 5~10 秒**，芝芝会出现在你的桌面上
3. 若 Windows SmartScreen 弹「已保护你的电脑」：点 **「更多信息」→「仍要运行」**（exe 未签名，属正常提示）

> 不需要安装 Node、Python 或任何依赖。退出请用**系统托盘图标右键 → 退出**（点 X 只是隐藏）。

## 基本玩法

| 操作 | 效果 |
|---|---|
| **按住芝芝拖动** | 芝芝迈步走路跟着你，松手站定（跨屏随意拖） |
| **左键点击头 / 身体** | 摸头（享受脸）、戳一戳（嗔怪吐槽） |
| **右键芝芝** | 完整菜单（下图功能全在这） |
| **菜单 → 对话** | 顶部弹出输入条，直接和芝芝说话（见下文三档回复） |
| **菜单 → 动作** | 挥手问候 / 开心转圈 / 嗔怪跺脚 / 伸个懒腰 / 撒花庆祝 |
| **菜单 → 调整大小** | 大（400px）/ 中 / 小 三档等比缩放，选择会记住 |
| **菜单 → 隐藏芝芝** | 整只收进系统托盘，托盘「显示芝芝」找回 |
| **托盘右键** | 显示/隐藏、窗口置顶、打开设置页、退出 |

芝芝还会自己呼吸、眨眼、偶尔踮脚伸展，深夜会催你休息。夸她「好看/喜欢你」会害羞，惹她会嗔怪——多聊几句，「芝士就是力量」就出现了。

## 对话的三档回复

1. **本地台词（默认，开箱即用）**：内置御姐语料规则匹配，秒回，离线可用
2. **GLM 大模型（可选）**：托盘 → 打开设置页 → 「GLM API」卡片粘贴你自己的 API Key（如智谱 coding plan 的 key）→ 保存。之后闲聊全部由大模型生成，额度按你的 key 账户计
3. **「让ZCode 帮我……」**：对话里以「让ZCode」开头，任务会转交给电脑上的 ZCode 会话执行，完成后芝芝播报回信（需要该电脑在用 ZCode）

**中文输入法注意**：第一下回车是选字上屏，**再按一下回车**才发送。

## 读取记忆（默认关闭）

右键 → 「读取记忆」打开后，芝芝会读取**你本机 ZCode 的会话记录**（`~/.zcode/cli/rollout/`），记得你最近和 ZCode 聊了什么——你问她「刚才聊了什么」她能引用你的原话。

- 纯本地读取，不需要 API Key，**绝不出网、绝不上传**
- 没装 ZCode 的电脑开了也没东西可读（设置页「最近读到的对话」可看到她实际读到了什么）
- 随时关闭，关闭即清空

## 隐私说明（重点）

- exe **没有任何上报/统计/埋点**，唯一的外网请求是「你配了 key 之后」发给智谱官方 API 的对话请求本身
- API Key 只存在你自己电脑的 `%APPDATA%\zhizhi` 下，不进仓库、不进安装包、不随分享传播
- 读取记忆只在开关打开时读本机文件

## 常见问题

**双击后没反应？** 等待 5~10 秒（首次自解压）；仍无反应检查杀毒软件是否拦截；再不行看任务栏托盘里是否已有图标（可能已在运行，双击第二次只会唤出已有芝芝）。

**打字没反应？** 点开「对话」后等半秒再打字；中文输入法要按**两下**回车。

**想换台电脑用？** 直接把 zhizhi.exe 拷过去，配置和记录都在各自电脑本地，互不干扰。

**声音？** 暂无语音，台词以气泡呈现。
